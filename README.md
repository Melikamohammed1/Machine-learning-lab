# Machine Learning Lab: Data Exploration & Foundational Math

Exploratory analysis of a student performance dataset using Python, pandas, NumPy, Matplotlib and SciPy.

- Cleans the data by removing missing values, the 50-hour study outlier and the impossible attendance value
- Summarizes each column with the mean, median and standard deviation
- Plots a histogram of final scores and a scatter plot of study hours vs final score
- Calculates the Pearson correlation and a prediction using a weight vector, dot product and bias
- Standardizes study_hours and previous_mark and explains why scaling matters for KNN
